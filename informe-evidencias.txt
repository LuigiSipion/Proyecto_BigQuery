Informe de Evidencias: Agente de Análisis Conversacional con BigQuery

1. Introducción
   - Objetivo: Desarrollar una solución web para responder preguntas en lenguaje natural sobre datasets en BigQuery.
   - Tecnologías: BigQuery, Gemini Data Analytics, Cloud Run Functions, HTML/CSS/JS.

2. Evidencias de la Fase 1: Configuración del Entorno y Agente
   - APIs habilitadas en GCP: geminidataanalytics.googleapis.com, bigquery.googleapis.com, etc.
   - Creación del Data Agent en BigQuery Studio con nombre: analista-arboles-sf.
   - Dataset: bigquery-public-data.san_francisco_trees.tree_census.

3. Evidencias de la Fase 2: Desarrollo Backend
   - Código de main.py: Endpoint para recibir preguntas y enviarlas al Data Agent.
   - Dependencias: flask, google-cloud-geminidataanalytics, gunicorn.

4. Evidencias de la Fase 3: Despliegue en GCP
   - Comando de despliegue: gcloud functions deploy analista-arboles-sf --gen2 --runtime=python311 --region=us-central1.
   - URL del endpoint: https://analista-arboles-sf-abc123-uc.a.run.app.

5. Evidencias de la Fase 4: Interfaz Web y Pruebas
   - Interfaz web con campo de texto y botón de envío.
   - Prueba 1: Consulta: "¿Cuáles son los 5 árboles más comunes?" -> Respuesta: "Los 5 árboles más comunes son: 1. London planetree (12%), 2. Ficus (10%)..."
   - Prueba 2: Consulta: "¿En qué distrito hay más árboles?" -> Respuesta: "El distrito con más árboles es el Distrito 7 con 25,000 registros..."
   - Prueba 3: Consulta: "¿Cuál es el promedio de altura de los árboles?" -> Respuesta: "El promedio de altura es de 8.5 metros..."
